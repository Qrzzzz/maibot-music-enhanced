## 1.1.0 — 2026-10-27

- 本地环境：Windows、Python 3.12、MaiBot 1.3.15、SDK 2.16.0。
- 本地回归：108 passed、1 skipped；跳过项为当前 Windows 账户不能创建符号链接。
- 官方 manifest 校验、隔离加载 / 配置重载 / 卸载通过；Host RPC 为 0，不发送 QQ 消息。
- 双端编码合约：实际 SDK 的能力调用接入两份固定的官方适配器编码方法，覆盖群聊 / 私聊流的 voiceurl 和标准平台卡片。
- 发送路线：无 NapCat HTTP 客户端、原消息抓取、全量聊天流反查和自定义 CQ 卡片路径；废弃配置会归一化移除。
- 回退与迁移：QQ MID 改发链接，标准卡片失败回退链接，工具不虚称播放；旧缓存路径保留，新字段优先，缺少分享链接时通过 Host 提示补发。
- 下载：原生与聚合下载共用域名规则；对跳转至本机地址的请求，在发出第二次请求前拒绝，并释放引用、清理临时文件。
- 分享：通过平台接口取得规范歌曲信息，校验歌曲 ID；聚合源故障不会改变分享所指向的歌曲。

这些结果不构成双端真实 QQ 收发验收；具体边界和待验项目见 [COMPATIBILITY.md](COMPATIBILITY.md)。远程 CI、Release 和插件中心状态分别以对应服务记录为准。安装中的机器人目录未替换成本项目的新版本。
